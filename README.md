Just made a travel and tourism web application with React that allows users to explore domestic and international travel destinations, browse tour packages, view popular destinations, explore travel services, check FAQs, and contact the travel agency. The project focuses on creating an engaging travel experience through destination videos, interactive package cards, animated counters, travel service sections, image galleries, FAQ interactions, and responsive layouts.

## ✨ Features
- Domestic and international tour packages
- Destination-based travel packages
- Interactive package tabs
- Hover-to-play destination videos
- Automatic destination slideshow
- Recent tour section
- Flight, Hotel, Cruise, Train, Bus booking service
- Travel memories/image gallery
- Destination names displayed on gallery images
- FAQ section
- Custom travel enquiry form
- Contact section
- Social media links
- Scroll-based animations
- Responsive design (pc and phone only)
